# 04 — UX

> Status: **APPROVED / PRODUCTION UX (v0.3.0)**  
> Application: **MagicBridge** (`magicbridge.exe`, unified binary & `MagicBridge-Setup.exe`)

## Tray icon (always present in background mode)
- Icon shows state: normal / paused / keyboard disconnected / dynamic battery level badge.
- Tooltip: `MagicBridge — Bluetooth — Battery 78% — Profile: Default (IT) — Media keys first`.
- Right-click menu:
  - ✅ Enabled (toggle, same as the pause hotkey)
  - Profile: ◉ Default (IT) / ○ English (US) / ○ Gaming …
  - Top row: ◉ Media keys first / ○ F-keys first
  - Open settings…
  - Start with Windows ✓
  - Quit
- Double-click opens settings immediately.
- Automatic low-battery balloon/toast notification when battery drops below threshold.

## Settings window (`magicbridge.exe`)
Responsive window with fluid visual scaling, theme support, and adaptive navigation layout:
- **Expanded Mode (&ge; 850px):** Full-width navigation tab bar with descriptive labels, persistent top-rail battery & connection status pill (`🔋 85%` or `⚡ A1843 Connected`), and side-by-side key inspector.
- **Compact Mode (< 850px):** Icon-only navigation rail with tooltips, dynamic vertical stacking, and clamped key dimensions (`key_size = clamp(available_width / 24.5, 20.0, 42.0)`).

### Navigation Tabs:
1. **⌨️ Keyboard** (main layout view)
   - **Profile bar** at top: active profile dropdown + *New*, *Duplicate*, *Rename*, *Delete* buttons, auto-detect button, and **Language/Physical Layout** selector with dynamic Windows PC detected layouts + worldwide catalog (Italian, US, UK, German, French, Spanish, Portuguese, Swiss, Nordic, Japanese JIS, Dutch, Polish, Russian, Ukrainian, Turkish, Czech, Hungarian, Greek, Arabic, Hebrew, Korean, Chinese, and Custom).
   - Visual A1843 keyboard drawn to scale with aluminum plate bezel, numpad, and F13–F19.
   - **Keyboard Scale / Zoom Control**: Segments for `Fit`, `90%`, `100%`, and `115%` to scale keycap dimensions to user preference.
   - **Color Legend**: Remapped (Blue), Cmd ↔ Alt Swap (Green), Fn Trigger Key (Orange), Selected (Gold).
   - Layer switch: **Normal** | **Fn**.
   - Re-clicking the selected key deselects it; dedicated `[Deselect Key]` button.
   - Presets dropdown: *Windows layout*, *Mac layout*, *Reset all*.
   - **Key Editor Side Panel**:
     - 1-click **Quick Presets** for missing Windows keys (`PrintScreen`, `ScrollLock`, `Pause`, `Insert`, `Delete`).
     - **Interactive Key Filter**: Real-time search filter box to instantly find key names (`F1`..`F19`, `Volume`, `Ctrl`, `Command`, etc.).
     - Action types: *Remap Key*, *Media Command*, *Launch Program*, *Open URL*, *Send Shortcut*.
2. **🪄 Setup Wizard**: 5-step progressive Windows installation & onboarding flow (Welcome, Options, Installing with animated progress bar, Hardware detection & layout setup, Ready).
3. **🧪 Hardware QA**: 109-key interactive diagnostic test matrix with live modifier state listeners and timestamped QA report export.
4. **🔉 Top Row & Fn**: Media-first / F-keys-first mode; toggle hotkey; Fn fallback key choice.
5. **🔋 Battery**: Current level, charging status, notification threshold, poll interval, dynamic tray badge toggle.
6. **⚙️ General**:
   - UI language (English / Italiano).
   - **Color Theme**: `System Default`, `Dark`, `Light` with real-time visual application.
   - Autostart at Windows login (HKCU, zero elevation).
   - Global pause hotkey.
   - Game mode process list.
   - Debug logging.
   - Configuration Import & Export.
   - Standalone Installation / Uninstallation management.
7. **🤖 Architecture**: Interactive didactic architecture diagrams, multi-agent methodology breakdown, and GitHub links.
8. **ℹ️ About**: Version, project links, daemon diagnostic status card, transport, and device detection.

## Behaviour
- Every change is saved and applied immediately. No "Apply" button.
- If the agent isn't running, the GUI shows a banner with a "Start agent" button.
- Closing the window exits the settings process completely. Zero idle RAM.
